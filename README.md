## About

I work across the whole stack, from the first migration to the server that serves the response.

On the application side I build Laravel systems with Inertia and Vue &mdash; multi-role admin
platforms, REST APIs, queued background jobs, authentication and permission layers &mdash;
and Next.js front ends for the public-facing side of the same products.

On the systems side I provision and operate the environments they run on. I have built and
maintained a complete shared-hosting platform: DirectAdmin for account and panel management,
CloudLinux for tenant isolation and per-account resource limits, Imunify360 for server
hardening and malware defence, JetBackup for scheduled backup and restore, Nginx and Apache
with tuned PHP-FPM pools, MySQL, DNS, and Cloudflare in front of it.

Between those two sides sits the work that actually keeps a product running: schema design,
deployments, SSL, cron and queue workers, transactional mail delivery, monitoring, and the
unglamorous maintenance that starts the day after launch and never stops.

I am self-taught. Everything above was learned by building it, breaking it, and keeping it online.

## Selected Work

Most of what I build is client and production work in private repositories, so this profile
shows only a small part of it. Recent examples:

**Operations platform** &mdash; a Laravel, Inertia and Vue application covering leads, clients,
projects and milestones, with role-based team permissions, queued transactional email, and a
separate invitation-only client portal running on its own authentication guard and a strict
default-deny visibility model.

**Marketing front end** &mdash; a Next.js site deployed alongside that platform, sharing one
domain and one server, submitting to a narrow rate-limited public endpoint rather than the
internal application.

**Shared hosting environment** &mdash; a hosting platform built from bare server upward:
provisioning, panel and account structure, tenant resource limits, security hardening,
scheduled backups, DNS, and CDN.

Happy to walk through any of these in detail.
